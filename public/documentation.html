Getting Started

Welcome to the documentation for Your Awesome Desktop App. This guide will walk you through the initial setup and basic usage.

Installation

  1. Download the latest version from the homepage.
  2. Run the installer `YourAwesomeApp-Setup.exe` (Windows) or `YourAwesomeApp.dmg` (macOS).
  3. Follow the on-screen instructions.
  4. Launch the app from your Applications folder or Start Menu.

Configuration

The app's settings can be configured via a config.json file located in your user data directory. Here is an example configuration:

{
  "theme": "dark",
  "autoSave": true,
  "defaultExportFormat": "pdf"
}

Available Options

  • theme: Can be "light", "dark", or "system". Defaults to "system".
  • autoSave: true or false. Determines if work is saved automatically.
  • defaultExportFormat: "pdf", "docx", or "txt".

API Reference

For advanced users, the app exposes a simple local API for scripting and integration.

Example: Create a New File

You can send a POST request to create a new file:

POST /api/v1/files
Host: localhost:8888
Content-Type: application/json

{
  "title": "My New Document",
  "content": "Hello, world!"
}

Frequently Asked Questions (FAQ)

How do I change the theme?

You can toggle the theme between light and dark mode using the ☀️/🌙 icon in the top right corner of the application window.

Where are my files saved?

By default, all your files are saved in the 'Documents/YourAwesomeApp' folder on your computer.
